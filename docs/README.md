# soniks-orbit — документация

Сервис определения и уточнения орбитальных параметров по наблюдениям сети СОНИКС.
Заменяет ручной процесс из четырёх консольных инструментов одним веб-разделом.

## Что это делает

Пользователь выбирает спутник и несколько наблюдений. Сервис сам вытаскивает
доплеровский трек из водопадов, человек правит его мышью, жмёт «фит» —
и получает TLE, которое можно опубликовать в каталог СОНИКС.

Два сценария:

- **Уточнение** — предстартовое расчётное TLE уточняется по наблюдениям, пока
  Space-Track ещё не выдал параметры. То же при сходе с орбиты, где уточнять нужно
  часто, вплоть до каждого наблюдения.
- **Идентификация** — сопоставление неопознанных объектов каталога с принятыми
  сигналами по минимальному RMS, автоматически, с подтверждением человеком.

Помимо этого репозитория затрагиваются два: `soniks-frontend` получает раздел,
`soniks-network` — четыре мелкие правки для публикации TLE. Клиент станции
не трогается. Подробности в [integration.md](integration.md).

## Происхождение

Сервис воспроизводит и заменяет процесс, описанный в `../../tle-making-guide.txt`,
который использует:

| Инструмент | Что делал | Чем заменён |
|---|---|---|
| `soniks-waterfall-tabulation-helper` | клики по водопаду → `.dat` | автоизвлечение трека + панель правки |
| `strf/rffit` | интерактивный фит через PGPLOT/X11 | `domain/od/fit.py` + панель невязок |
| `ikhnosoniks` | наложение предсказанной кривой | модельная кривая поверх водопада |
| `sattools/propagate` | перенос эпохи TLE | `domain/od/reepoch.py` |

Математика `rffit` портирована намеренно близко — он остаётся **эталоном
для регрессионных тестов**, см. [testing.md](testing.md).
