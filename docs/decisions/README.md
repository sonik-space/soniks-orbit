# Решения

По одному файлу на решение. Каждый фиксирует не только выбор, но и
**отвергнутые варианты с причиной** — иначе в следующей сессии они всплывут заново
и будут обсуждаться с нуля.

Три решения помечены как исправления прежних:

- **005** отменяет идею писать Django-приложение в монолите — она не учитывала
  срок жизни монолита;
- **010** исправляет неверное утверждение, что механизм свежести решает сценарий
  схода с орбиты бесплатно — семёрка там подгонялась задним числом;
- **015** снимает автоизвлечение трека целиком: замер на разметке человека
  показал, что оно садилось на нескорректированную помеху, а числа, которыми
  его качество подтверждалось, были получены по тем же неверным трекам.

**011 и 012 отложены, а не отменены.** Формат артефакта, требования к нему
и обоснование проработаны полностью — при необходимости это берётся и делается
без повторного разбора. Условия возврата перечислены в шапке 011.

Разборы отменённых и отложенных вариантов сохранены целиком. Аргументы за них
выглядели убедительно, поэтому без записи они вернутся.
